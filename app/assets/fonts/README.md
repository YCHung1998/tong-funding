# Bundled fonts

| File | Source | License |
|---|---|---|
| IBMPlexMono-Regular / Medium / SemiBold.ttf | https://github.com/google/fonts/tree/main/ofl/ibmplexmono | SIL OFL 1.1 (`OFL-IBMPlexMono.txt`) |

Regenerate with `python3 tools/build_fonts.py` (needs `fonttools`, network).

Chinese is intentionally not bundled; it renders with the macOS system CJK font.
See `openspec/changes/bootstrap-gpui-shell/design.md` ("字型實測").
